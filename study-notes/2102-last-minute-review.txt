10. Unit II No. 5 - (x − 3)y′ + 2y = 0
============================================================

y = sum_{n=0}^{infinity} c_n x^n
y′ = sum_{n=0}^{infinity} (n+1)c_{n+1}x^n

Substitute ပြီး coefficient comparison လုပ်လျှင်:
(n + 2)c_n − 3(n + 1)c_{n+1} = 0

c_{n+1} = (n + 2)c_n / [3(n + 1)]
c_n = (n + 1)c_0 / 3ⁿ

Series:
y = c_0[1 + 2(x/3) + 3(x/3)² + 4(x/3)³ + ⋯]

Radius:
R = 3

============================================================
11. Unit II No. 6 - (x − 1)y′ + 2y = 0
============================================================

Unit II No. 5 နှင့် အဆင့်တူပြီး 3 နေရာတွင် 1 ပြောင်း။

(n + 2)c_n − (n + 1)c_{n+1} = 0
c_{n+1} = (n + 2)c_n/(n + 1)
c_n = (n + 1)c_0

Series:
y = c_0[1 + 2x + 3x² + 4x³ + ⋯]

Radius:
R = 1

General shortcut:
(x − a)y′ + 2y = 0

c_{n+1} = (n + 2)c_n/[a(n + 1)]
c_n = (n + 1)c_0/aⁿ
R = |a|

12. Unit II No. 2 / Assignment 2 No. 4 - y″ + y = 0
============================================================

y = sum_{n=0}^{infinity} c_n x^n
y″ = sum_{n=0}^{infinity} (n+2)(n+1)c_{n+2}x^n

(n + 2)(n + 1)c_{n+2} + c_n = 0

c_{n+2} = −c_n/[(n+2)(n+1)]

Even powers နှင့် odd powers ခွဲလျှင်:

y = c_0(1 − x²/2! + x⁴/4! − ⋯)
  + c_1(x − x³/3! + x⁵/5! − ⋯)

Final:
y = c_0 cos x + c_1 sin x
