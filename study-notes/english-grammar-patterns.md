# English Grammar Patterns — Exam Quick Notes

ဒီ note သည် ပုံထဲတွင် စာမေးပွဲအတွက် ဖော်ပြထားသော grammar pattern ၂၀ ကို အမြန်ပြန်ကြည့်ရန် စုထားခြင်းဖြစ်သည်။ အလွတ်ကျက်ရာတွင် **ပုံစံ → ဘယ်အချိန်သုံး → စာကြောင်းဥပမာ** အစဉ်အတိုင်း မှတ်ပါ။

## အရင်ဆုံး မှတ်ထားရမည့် အတိုကောက်

- **S** = subject (လုပ်သူ/အကြောင်းအရာ)၊ **V** = verb (ကြိယာ)၊ **O** = object (အပြုခံ)
- **V1** = မူရင်းကြိယာ `go`၊ **V2** = အတိတ်ပုံစံ `went`၊ **V3** = past participle `gone`
- **V-ing** = `going`, `reading` ကဲ့သို့ `-ing` ပုံစံ
- Perfect မှာ **have/has/had + V3**၊ Continuous မှာ **be + V-ing**၊ Modal နောက်မှာ **V1** လိုက်သည်။

## A. Tense ပုံစံ ၄ မျိုး

| No. | မှတ်ရန်ပုံစံ | ဘယ်အခါသုံးသလဲ | ဥပမာ |
|---|---|---|---|
| **1. Present Perfect** | `S + have/has + V3` | အတိတ်ကဖြစ်ပြီး ယခုနှင့် ဆက်စပ်နေ၊ အတွေ့အကြုံ၊ သို့မဟုတ် အချိန်မပြီးသေး။ `I/you/we/they have`; `he/she/it has`။ | `She has finished her work.` — သူမ အလုပ်ပြီးသွားပြီ။ |
| **2. Past Perfect** | `S + had + V3` | အတိတ်ဖြစ်ရပ် ၂ ခုအနက် **အရင်ဖြစ်ပြီးသား** ကိုပြရန်။ | `The train had left before we arrived.` — ကျွန်တော်တို့မရောက်ခင် ရထားထွက်သွားခဲ့ပြီ။ |
| **3. Present Continuous** | `S + am/is/are + V-ing` | အခုလုပ်နေဆဲ၊ ယာယီဖြစ်နေဆဲ။ `I am`; `he/she/it is`; `you/we/they are`။ | `They are studying now.` — အခု စာလုပ်နေကြတယ်။ |
| **4. Past Continuous** | `S + was/were + V-ing` | အတိတ်အချိန်တစ်ခုမှာ လုပ်နေဆဲဖြစ်ပြီး အခြားဖြစ်ရပ်တစ်ခု ဖြစ်လာခြင်း။ `I/he/she/it was`; `you/we/they were`။ | `I was reading when he called.` — သူဖုန်းဆက်ချိန်မှာ ကျွန်တော် စာဖတ်နေခဲ့တယ်။ |

**အမှားမလုပ်ရန်:** `yesterday`, `last week` လို အတိတ်အချိန်ပြီးဆုံးကြောင်းပြတဲ့ စကားနဲ့ Present Perfect ကို ပုံမှန်အားဖြင့် မတွဲပါ။ `had + V2` မဟုတ်ဘဲ `had + V3` ဖြစ်သည်။

## B. Sentence နှင့် verb-form pattern များ

| No. | မှတ်ရန်ပုံစံ | သုံးပုံနှင့် ဥပမာ |
|---|---|---|
| **5. It is / It was** | `It is/was + အလေးပေးလိုသောအပိုင်း + who/that + ကျန်စာကြောင်း` | လူကို အလေးပေးလျှင် `who`, အရာ/အချိန်/နေရာကို အလေးပေးလျှင် `that` သုံးနိုင်သည်။ `Mya helped me.` → `It was Mya who helped me.` / `He arrived yesterday.` → `It was yesterday that he arrived.` အချိန်က အတိတ်ဆို `was` ကိုသုံးပါ။ `It is/was + adjective + to V1` (`It is easy to learn.`) ဆိုသော ပုံစံကို မေးလျှင်လည်း `It` သည် ယေဘုယျ subject ဖြစ်သည်။ |
| **6. Modal** *(ပုံတွင် “Model” ဟုရေးထား)* | `can/could/may/might/must/should/will/would + V1` | Modal သည် လုပ်နိုင်ခြင်း၊ ဖြစ်နိုင်ခြင်း၊ လိုအပ်ခြင်း၊ အကြံပေးခြင်း စသည်ကို ပြသည်။ `She can swim.` `He may come.` Modal နောက်တွင် `to` မထည့်၊ `V-s` မထည့်ပါ။ |
| **7. It is possible that … (may)** | `It is possible that + S + may + V1` | တစ်ခုခုဖြစ်နိုင်ကြောင်း ပြသည်။ `It is possible that it may rain.` — မိုးရွာနိုင်သည်။ `may` နောက်တွင် `V1`။ |
| **8. Omit relative pronoun** | Relative pronoun ချန်ခြင်း၊ သို့မဟုတ် clause ကိုအတိုချုံးခြင်း | ပုံမှန်အားဖြင့် relative pronoun ကို **object** ဖြစ်တဲ့အခါ တစ်လုံးတည်းချန်နိုင်သည်။ Pronoun က **subject** ဖြစ်လျှင် pronoun တစ်လုံးတည်းကိုမဖျက်ဘဲ PDF tip အတိုင်း relative clause ကို V-ing/V3 နဲ့ အတိုချုံးနိုင်သည်။ အသေးစိတ် formula များကို အောက်မှာကြည့်ပါ။ |
| **9. To + V1** | `to + မူရင်းကြိယာ` | ရည်ရွယ်ချက် သို့မဟုတ် ကြိယာတချို့နောက်တွင် သုံးသည်။ `I went to the library to study.` — စာလုပ်ရန် စာကြည့်တိုက်သွားခဲ့သည်။ `want/hope/decide + to + V1`။ သတိ: `look forward to` မှာ `to` သည် preposition ဖြစ်လို့ `V-ing` လိုက်သည် (`look forward to meeting`)။ |
| **10. V-ing** | `V-ing` | ဝါကျ၏ subject (`Reading is useful`), `enjoy/avoid/finish` နောက် (`She enjoys reading`), သို့မဟုတ် Continuous tense (`is reading`) တွင်တွေ့ရသည်။ စကားလုံးရှေ့က pattern ကိုကြည့်ပြီး သုံးပါ။ |
| **11. Without + V-ing** | `without + V-ing` | `without` သည် preposition ဖြစ်သောကြောင့် နောက်တွင် နာမ် သို့မဟုတ် V-ing လိုက်သည်။ `He left without saying goodbye.` — နှုတ်မဆက်ဘဲ ထွက်သွားသည်။ |
| **12. By + V-ing** | `by + V-ing` | “ဘယ်လိုနည်းနဲ့ လုပ်သလဲ” ကိုပြသည်။ `You can improve by practising every day.` — နေ့တိုင်းလေ့ကျင့်ခြင်းအားဖြင့် တိုးတက်နိုင်သည်။ `by` နောက် `V1` မဟုတ်ဘဲ `V-ing`။ |

### No. 8 — Relative Pronoun ကို ချန်ခြင်း / Clause ကို အတိုချုံးခြင်း

`Relative pronoun (R.P.)` ဆိုတာ နာမ်ကို နောက်က clause နဲ့ ဆက်ပေးတဲ့ `who, whom, which, that` စကားလုံးတွေပါ။ နာမ်ကို အရင်ဆုံးရှာပြီး အဲဒီနာမ်နောက်က အပိုင်းက ဘယ်သူ/ဘာကို ဖော်ပြနေလဲ စစ်ပါ။

#### နည်းလမ်း 1 — Object ဖြစ်လို့ R.P. တစ်လုံးတည်း ချန်ခြင်း

ပုံစံက `noun + R.P. + subject + verb` ဖြစ်သည်။ R.P. နောက်မှာ **လုပ်သူ subject** တစ်ခုရှိနေပြီး R.P. ကိုယ်တိုင်က လုပ်ဆောင်မှုရဲ့ object ဖြစ်လျှင် R.P. ကိုသာ ဖယ်ပါ။ ကျန် clause ကို မပြောင်းပါနှင့်။

- `The cake (that) my sister baked is delicious.`
- `my sister` က `baked` လုပ်သူ၊ `that` က baked လုပ်ခံရတဲ့ cake ဖြစ်လို့ `that` ကို ချန်နိုင်သည်။

#### နည်းလမ်း 2 — Subject ဖြစ်တဲ့ R.P. နဲ့ clause ကို အတိုချုံးခြင်း

R.P. နောက်မှာ verb တန်းလိုက်ပြီး အဲဒီ verb ကို လုပ်သူ subject မရှိလျှင် R.P. ကိုယ်တိုင်က **subject** ဖြစ်သည်။ ဒီအခါ pronoun ကိုတစ်လုံးတည်း မဖျက်ပါနှင့်။ PDF မှာပြထားတဲ့အတိုင်း အောက်ပါပုံစံများဖြင့် clause ကို လျှော့ပါ။

| PDF tip ပုံစံ | အတိုချုံးနည်း | ဥပမာ |
|---|---|---|
| `R.P. + active verb` | R.P. ဖြုတ်၊ verb ကို `V-ing` ပြောင်း | `a boy who runs fast` → `a boy running fast` |
| `R.P. + be + V-ing` | R.P. နှင့် `be` ဖြုတ်၊ `V-ing` ကိုထား | `people who are waiting` → `people waiting` |
| `R.P. + be + V3` | R.P. နှင့် `be` ဖြုတ်၊ passive `V3` ကိုထား | `a report which was written in June` → `a report written in June` |
| `R.P. + has/have/had been + V3` | R.P. နှင့် auxiliary များဖြုတ်၊ passive `V3` ကိုထား | `forms that have been signed` → `forms signed` |

PDF ထဲက `R.P. + subject + verb` ဆိုတဲ့ tip က ပထမနည်း — object R.P. ကိုပဲ ချန်ခြင်း — ဖြစ်သည်။ ကျန် tip သုံးခုက R.P. သည် subject ဖြစ်နေသည့် clause ကို အတိုချုံးခြင်းဖြစ်သည်။ ဒါကြောင့် “relative pronoun အားလုံးကို ဖျက်လိုက်” ဆိုတဲ့ စည်းမျဉ်းတစ်ခုတည်းအဖြစ် မမှတ်ပါနှင့်။

#### အလွယ်ဆုံးဆုံးဖြတ်နည်း

R.P. ရှေ့ရှိ နာမ်နောက်က စာလုံးကိုကြည့်ပါ —

- `R.P. + subject + verb` → R.P. သည် object ဖြစ်နိုင်သည်။ **R.P. တစ်လုံးတည်းဖျက်**။ `the film (that) we watched`
- `R.P. + verb` → R.P. သည် subject ဖြစ်သည်။ **တစ်လုံးတည်းမဖျက်**; verb အမျိုးအစားကိုကြည့်ပြီး `V-ing` သို့မဟုတ် `V3` နဲ့ clause ကိုလျှော့။ `a person who works` → `a person working`

#### မကြာခဏမှားတတ်တာများနှင့် စစ်ဆေးချက်

- `who/which/that + subject + verb` တွင် R.P. ကိုသာဖျက်ရင် ပုံမှန်အားဖြင့် မှန်သည်။ `The song (that) she sang ...`
- `who/which/that + verb` တွင် pronoun က subject ဖြစ်နိုင်လို့ ရိုးရိုးဖျက်လိုက်ရင် clause ပျက်သွားသည်။ လျှော့ရေးရာ၌ verb ပုံစံကိုပါ ပြောင်းရသည်။
- Preposition ကို နောက်မှာထားလျှင် object R.P. ကိုချန်နိုင်သည် — `the hotel (that) we stayed in`။ Preposition ကို ရှေ့တင်ထားသည့် `the hotel in which we stayed` မှာ `which` ကို မချန်ပါနှင့်။
- Comma ပါသော non-defining clause (`My aunt, who lives in Mandalay, ...`) မှာ relative pronoun ကို မချန်ပါနှင့်။
- PDF ရဲ့ `has/have/had (+ been) + V3` tip ကို passive ပုံစံမှာ သုံးပါ။ Active perfect (`a student who has completed the course`) မှာ `who has` ကိုဖျက်ပြီး `student completed...` လို့ မရေးပါနှင့်; full clause ကိုထားပါ၊ သို့မဟုတ် သင်ခန်းစာက ခွင့်ပြုသော participle ပုံစံကိုသာသုံးပါ။

**သုံးဆင့်မှတ်ရန်:** (1) R.P. နောက်က `S` ကိုရှာ၊ (2) ရှိရင် object ဖြစ်လို့ pronoun တစ်လုံးတည်းချန်၊ မရှိဘဲ verb တန်းလာရင် subject ဖြစ်ကြောင်းသိ၊ (3) PDF ပုံစံအလိုက် `V-ing`/`V3` နဲ့ clause ကိုအတိုချုံးပြီး tense နဲ့ အဓိပ္ပာယ်မပြောင်းကြောင်းစစ်။

## C. တွဲဖက်စကားလုံးနှင့် အခြားအသုံးများ

| No. | မှတ်ရန်ပုံစံ | သုံးပုံနှင့် ဥပမာ |
|---|---|---|
| **13. Either … or / Neither … nor** | `Either A or B`; `Neither A nor B` | `either…or` = နှစ်ခုအနက် တစ်ခု၊ `neither…nor` = နှစ်ခုလုံး မဟုတ်။ တွဲထားသောအပိုင်းများကို ပုံစံတူထားပါ။ `You can either walk or take a bus.` / `She likes neither tea nor coffee.` |
| **14. Not only … but also** | `not only A but also B` | A နှင့် B ကို တွဲပြီး “A သာမက B လည်း” ဟု အလေးပေးသည်။ A/B သည် noun နှစ်ခု၊ verb နှစ်ခု စသည်ဖြင့် ပုံစံတူစေပါ။ `He is not only clever but also kind.` |
| **15. So … that** | `so + adjective/adverb + that + S + V` | “အလွန် … သောကြောင့် …”။ `The box was so heavy that I could not lift it.` (`heavy` = adjective) / `He ran so quickly that he won.` (`quickly` = adverb)။ `so` နောက် adjective/adverb၊ `that` နောက် ဝါကျအပြည့် လိုက်သည်။ |
| **16. Be about to** | `am/is/are/was/were + about to + V1` | ချက်ချင်းလုပ်တော့မည့်အရာ။ `The bus is about to leave.` — ဘတ်စ်ကား ထွက်တော့မည်။ `about to` နောက် `V1`။ |
| **17. Have to** | `have/has/had to + V1` | လုပ်ရမည်၊ လိုအပ်သည်။ `I have to go.` / `She has to go.` / `We had to wait.` အငြင်းနှင့် မေးခွန်းတွင် `do/does/did + have to` — `She doesn't have to go.` |
| **18. By means of** | `by means of + noun` | “...ကို အသုံးပြု၍ / ...နည်းလမ်းဖြင့်”။ `They travelled by means of a small boat.` — လှေငယ်တစ်စင်းကို အသုံးပြုပြီး ခရီးသွားခဲ့ကြသည်။ နောက်မှာ noun phrase ထားပါ။ |
| **19. Differ in … from** | `A differs in + noun + from B` | A နှင့် B ဘာအချက်မှာ ကွာခြားသည်ကို ပြသည်။ `This copy differs in colour from the original.` — ဒီမိတ္တူက မူရင်းနဲ့ အရောင်ကွာတယ်။ `A differs from B in colour` လို့လည်း ရေးနိုင်သည်။ |
| **20. As if** | `as if + S + V (past form)` | တကယ်မဟုတ်နိုင်သော အခြေအနေကို “...သလိုပဲ” ဟု နှိုင်းပြသည်။ ပုံထဲရှိ “Noun” သည် ဝါကျ၏ subject ကို ဆိုလိုသည် — noun တစ်လုံးတည်းမဟုတ်ပါ။ `He talks as if he knew everything.` — အကုန်သိသလို ပြောတယ်။ `be` ကို စာမေးပွဲပုံစံတွင် `were` သုံးတတ်သည်: `She acts as if she were the boss.` အတိတ်ဖြစ်ရပ်ကို “ဖြစ်ခဲ့သလို” ပြောလျှင် `as if + S + had + V3`: `He looked as if he had seen a ghost.` |

## မြန်မြန်ပြန်စစ်ရန်

1. **Perfect** → `have/has/had + V3`
2. **Continuous** → `am/is/are/was/were + V-ing`
3. **Modal / to / about to / have to** နောက် → `V1`
4. **without / by** နောက် → `V-ing`
5. **so** နောက် → adjective သို့မဟုတ် adverb; **that** နောက် → subject + verb ပါသော clause
6. Pattern ပြောင်းရေးရာတွင် အဓိပ္ပာယ်နှင့် tense ကို မပြောင်းပါနှင့်။ Verb ကိုရွေးပြီးတိုင်း subject နဲ့ကိုက်/မကိုက် စစ်ပါ။

## စာမေးပွဲဖြေသည့်အခါ လုပ်ရန် ၃ ဆင့်

1. မေးခွန်းထဲက အချက်ပြစကားကိုရှာပါ — ဥပမာ `since/for`, `when`, `without`, `either`, `as if`။
2. အဲဒီစကားနဲ့တွဲရမည့် formula ကိုရွေးပါ။
3. နောက်ဆုံးမှာ **V1/V3/V-ing**, subject-verb agreement, tense နဲ့ မူရင်းအဓိပ္ပာယ်ကို စစ်ပါ။
